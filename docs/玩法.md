# 玩家

# 房产（私有表面）

游戏初始时会提供一些房产。
管理员可以通过命令行删除和增加房产。
房产有不同属性。

通过UI界面，每个玩家可以查看所有房产、购买任意个房产、进入自己拥有的房产。
玩家可以设置最多 10 名好友；双方互为好友时可以进入对方房产。信用点可直接转账，无需确认且没有限额。
玩家也可以在个人页面把自己拥有的全部房产对所有玩家开放；此设置只授予进入权限。

## 房产动态属性

交易数据

* 所有者（初始无）
* 购买价格（初始固定值）P
* 购买时间
* 税率tax
* 持有周期T（2小时~32小时）

交易价格会向上取整。
通过上述数据，可以计算出房产是否可以购买（T是持有周期，新P成交价格=ceil(P×(1/10)^(t/T))，t是(now-购买时间)）
不分多个周期。
可以支付当前市场价的税率部分增加持有周期；每次续期最低 1 信用。
当房产被购买时，买方支付 新P成交价格，卖方获得 新P成交价格*(1-tax)。

## 房产静态属性

房产性质

* 面积大小
* 关联箱数目
* 太阳能强度 / 有无水 / 矿物
* 防护力度（被盗窃概率）

# 学习

消耗瓶子，提升对应的经验值。
每种瓶子的经验值的十进制位数，就是等级。0经验等级是0，1~9经验等级是1，10~99等级是2
经验与等级无上限。当前唯一作用是新建飞船宽度为 `总等级×2+16`，飞船地图高度最大 512。
