# 玩家

玩家可以领取低保 UBI，即随时间获得金币（内部保存在 `storage`，不是 Factorio 的金币物品实体）。
每位玩家首次建立账户时获得 1000 金币。
木箱手动放在星球上，变为关联箱。
每分钟在线玩家自动消耗关联箱的瓶子、给玩家获取金币（不是研究科技）。


# 环境

使用 太空时代DLC, spaceage。包括quality
五颗公共星球分别按 2、3、4、5、7 小时的周期错峰重建，并提前 30、5、1 分钟提醒。开始重建时关闭进入、撤离玩家到联合国难民营，换种并异步清空表面；完成后清除该星球的统计并重新开放，不重置科技。
每轮随机地图种子、太阳能倍率和昼夜长度；[planet=nauvis] 还会获得随机虫群进化度。
一个公共联合国难民营 surface，作为默认复活与灾难撤离点。

# 房产（私有表面）

游戏初始时会提供一些房产。
管理员可以在专用管理页创建、删除和修复房产，并动态调整常用场景设置。
房产有不同属性。

通过 UI 界面，每个玩家可以查看所有房产；购买/续期和进入使用独立按钮。玩家可进入自己的房产、双向好友的房产和屋主主动公开的房产。
玩家可以设置最多 10 名好友；双方互为好友时可以进入对方房产。金币可直接转账，无需确认且没有限额。
持有至少一套房产时，玩家可以在房产页面把自己拥有的全部房产对所有玩家开放；此设置只授予进入权限。

## 房产动态属性

交易数据

* 所有者（初始无）
* 上次实际成交价格 P（新房初始为 1000～2000）
* 购买时间
* 税率tax
* 回落周期 T（2 小时）与价格回落时间点 D

交易价格会向上取整，公式为 `min(1,000,000,000, max(1, ceil(P × 10^((D-now)/T))))`。
成交后本次价格成为新 P，D 设为 `now+2小时`；没有保护期，可以立即再次购买。
管理员设置基础税率，默认为 10%。交易税使用基础税率；设屋主总等级为 L，续期费率为 `基础税率 × 1/(L/100+1)`，最低续期费为 1 金币。每次让 D 增加 2 小时，最多延长到 `now+30小时`。
当房产被购买时，买方支付 新P成交价格，卖方获得 新P成交价格*(1-tax)。

## 房产静态属性

房产性质

* 面积大小
* 关联箱数目
* 太阳能强度 / 有无水 / 矿物
* 防护力度（被盗窃概率）

所有房产表面与 [planet=nauvis] 同步昼夜相位和昼夜长度，太阳能效率固定为 10%，夜间最低亮度固定为 0.05。surface 显示名、市场第一列和房屋上方 rendering 始终使用同一个房产名：未命名时无主显示“无主房产 + 编号”，有主显示“玩家名的房产 + 编号”；屋主使用命令重命名后，三处同时显示自定义名称。

# 学习

消耗瓶子，提升对应的经验值。
每种瓶子的经验值的十进制位数，就是等级。0经验等级是0，1~9经验等级是1，10~99等级是2
经验与等级无上限。当前唯一作用是新建飞船宽度为 `总等级×2+16`，飞船地图高度最大 512。
