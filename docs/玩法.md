# 太阳系联合国：简明玩法

## 最简流程

1. 点击左上角“传送”，前往本国公共星球并开始生产。
2. 在本国公共星球手动放置木箱，建立个人关联箱。
3. 关联箱不能手动打开。用机械臂投入科技瓶，科技瓶会变成个人经验。
4. 用经验和体力建造房产；也可以领取低保金币，购买本国现成房产。
5. 房产中央四个关联箱与个人关联箱共享物品。用机械臂连接两端，在星球跃迁前转移重要物资。

不需要先读完规则或理解公式。像普通 Factorio 一样生产，逐渐建立自己的安全据点即可。

## 房产交易

购买房产后，下一次报价会立即按当前房价倍率上涨，默认约为本次成交价的两倍。房款扣税后交给原屋主。

房产以后可能被其他玩家再次购买。原屋主会收到税后成交款，可以继续建造或购买新家，不会因此无法继续游戏。

房产有自己的寿命和降价周期。建造页面会直接显示本次房产的尺寸、寿命、初始价格和 T；精确公式可在游戏“规则数据”的信息图标中查看。

## 公共星球与安全地点

五颗公共星球会周期跃迁，每一轮都会生成新的随机世界。联合国难民营不会随星球跃迁消失；限时房产会在自身寿命结束时删除。

“传送”按钮在本国公共星球与本国难民营之间切换。“房产”按钮前往自己的房产；拥有多套时依次循环。

## 阵营

五个阵营分别拥有科技、建筑、房产市场和飞船。友好国家共享视野并开放建筑；敌对国家可能互相攻击。[planet=aquilo] 冰星阵营永久保持中立。

切换阵营会失去原阵营房产、飞船和个人关联箱。外星房产可以查看，但不能正常购买或进入。

## 其他玩法

- 科技瓶经验会提高总等级。等级影响新建飞船，并降低卖房税率。
- 玩家可以建设、交易、合作、外交、犯罪入侵或交战。
- 每轮公共星球拥有随机地形、资源和特色词条。
- 精确费用、概率、公式和管理员规则均放在游戏 tooltip 或“规则数据”中。
