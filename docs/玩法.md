# 玩家

玩家可以领取低保 UBI，即随时间获得金币（内部保存在 `storage`，不是 Factorio 的金币物品实体）。
每位玩家首次建立账户时获得 1000 金币。
木箱手动放在星球上，变为关联箱。
每分钟在线玩家自动消耗关联箱的瓶子、给玩家获取金币（不是研究科技）。


# 环境

使用 太空时代DLC, spaceage。包括quality
五颗公共星球分别按 2、3、4、5、7 小时的周期错峰重建，并提前 30、5、1 分钟提醒。开始重建时关闭进入、撤离玩家到联合国难民营，换种并异步清空表面；完成后清除该星球的统计并重新开放，不重置科技。
每轮随机地图种子、太阳能倍率和昼夜长度；[planet=nauvis] 还会获得随机虫群进化度。
五颗公共星球各有一个 64×64 联合国难民营 surface，作为该星球的复活与灾难撤离点。

# 房产（私有表面）

游戏初始时会提供一些房产。
管理员可以在专用管理页创建、删除和修复房产，并动态调整常用场景设置。管理员默认不能绕过权限进入任意房产；该能力可由管理页开关临时启用。
房产有不同属性。

通过 UI 界面，每个玩家可以查看所有房产；购买和进入使用独立按钮。玩家可进入自己的房产、双向好友的房产和屋主主动公开的房产。
玩家可以设置最多 10 名好友；双方互为好友时可以进入对方房产。金币可直接转账，无需确认；每次至少转 1000 金币，手续费 `max(100, ceil(金额×0.1%))` 从收款所得扣除，付款方只支付转账金额。
持有至少一套房产时，玩家可以在房产页面把自己拥有的全部房产对所有玩家开放；此设置只授予进入权限。

## 房产动态属性

交易数据

* 所有者（初始无）
* 上次实际成交价格 P（新房初始为 1000～2000）
* 购买时间
* 税率tax
* 类型与回落周期 T（短租房 2 小时、长租房 20 小时）
* 价格回落时间点 D

交易价格会向上取整，公式为 `min(1,000,000,000, max(1, ceil(P × a^((D-now)/T))))`；管理员可设置 `1<a<100` 的倍率 a，默认 2。
成交后本次价格成为新 P，D 设为 `now+T`；没有保护期，可以立即再次购买。
管理员设置基础税率，默认为 10%。设卖方总等级为 L，实际税率为 `基础税率 × 1/(L/100+1)`。买方支付完整成交价，卖方获得扣税后的金额。
屋主点击购买自己的房产时仍是一笔正常交易：完整报价成为新 P、D 重设为 `now+T`，屋主收回税后所得，因此余额净减少本次税款。
其他品质相同时，推荐成交价与 T 成正比，因此长租房参考价约为短租房的 10 倍。

## 房产静态属性

房产性质

* 面积大小
* 关联箱数目
* 太阳能强度 / 有无水 / 矿物
* 防护力度（被盗窃概率）

房产分属五颗公共星球，房产页按星球分为五个页签。每套房产只从所属星球复制地貌并同步其昼夜；太阳能效率固定为 10%，夜间最低亮度固定为 0.05。无主房产 surface 对玩家势力可见，有主房产隐藏。surface 显示名、市场第一列和房屋上方 rendering 始终使用同一个房产名。

# 学习

消耗瓶子，提升对应的经验值。
每种瓶子的经验值的十进制位数，就是等级。0经验等级是0，1~9经验等级是1，10~99等级是2
经验与等级无上限。设总等级为 L：新建飞船宽度为 `16+2L`，寿命为 `管理员基础寿命+L` 小时；作为房产卖方时，实际税率为 `基础税率/(L/100+1)`。飞船属性在建造时固定，之后升级不追溯修改。
