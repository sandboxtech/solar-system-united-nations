# 阶段 3 游戏内验证

## 初始化与联合国难民营

1. 新场景启动后确认每颗星球有三套永久 64×32 基准房和一套永久 128×64 基准房，除此之外没有系统限时房产。
2. 管理员页不再提供动态房产供给、管理员创建或管理员删除入口。
3. 左上角只显示一个 United Nations of Sol 主菜单按钮和一个地图标记“家”按钮。
4. 从公共星球点击“家”，应前往该星球最近到访且仍自有的房产；没有自有房产时应前往该星球难民营。从房产或难民营点击则返回对应星球原点。
5. 从窗口的文字、表格、空白和内容区域拖动，确认整个非交互区域都可以移动窗口，按钮仍可正常点击。
6. 在房产页点击“前往联合国难民营”，确认安全传送到 64×64 的“联合国难民营”原点附近；中心 32×32 应为教学网格，外围陆地应符合所属星球，最外两格应为该星球的代表液体地砖。
7. 在任意星球难民营点击“家”，确认前往对应公共星球原点附近的空位。
8. 进入载具后尝试传送，确认系统拒绝并提示先离开载具。
9. 没有个人关联箱时死亡并复活，确认最终位于联合国难民营原点附近。

## 关联箱传送与复活

1. 在 [planet=nauvis] 手动放置木箱，确认它被替换为个人关联箱。
2. 在其他星球或私人表面放置木箱，确认它仍然是普通木箱。
3. 确认主窗口有“玩法说明、个人、建造、房产、星球、飞船、玩家”页面；个人页显示低保、经验和自杀，飞船页顶部显示建造与拆除操作。
4. 离开该表面后点击“前往星球”，确认抵达关联箱附近的空位。
5. 角色死亡并复活，确认最终抵达关联箱附近的空位。
6. 挖掉关联箱不会改变“家”按钮的五星往返逻辑。
7. 再次死亡和点击“前往星球”，分别确认回到联合国难民营原点附近和 [planet=nauvis] 原点附近。
8. 用实体堵住目标附近所有安全落点，确认传送不会报错，而是强制抵达目标表面的 `(0, 2)`。

## 房价与购买

1. “房产”页面显示紧凑房产列表：房产、所有者、剩余寿命、当前价格和操作。
2. 第一次点击“购买”，按钮变为“确认 当前报价”，但不立即扣款。
3. 再次点击确认，确认扣除当前价格并取得产权。
4. 管理员把 a 设为 2；成交前价格为 `P`，成交后立即观察，下一次购买价应接近 `2P`。
5. 等待 20 小时，确认玩家新建房产的价格回落到本次成交价 `P`，之后继续下降，最低为 1。
6. 如果确认前另一名玩家购买或屋主自购使价格上涨，旧报价应被拒绝并刷新。
7. 成交后确认所有在线玩家都收到买方、成交价、房产名、卖方（如有）、卖方实收及税款。

## 玩家建造与总寿命

1. 分别选择 30/120/480 小时，确认寿命成本档为 1/3/5；分别选择 64×32/128×64/256×128，确认尺寸成本档为 1/3/5。
2. 五颗星球依次显示自动化（红瓶）、冶金、农业、电磁和低温科技包经验；经验与金币费用均为 `1000×寿命成本×尺寸成本`。
3. 经验或金币不足时按钮禁用；补足后二次确认建造，确认永久扣除指定科技包经验和等额金币，其他经验不变。
4. 建成房产立即归建造者所有，只复制所选星球的自然地貌，并出现在对应星球房产页；确认初始 `P=10×经验成本`、`D=建造时刻`。
5. 成功后立即再次打开建造页，确认 20 小时冷却倒计时可见且不能建造；失败或取消不会进入冷却。
6. 交易房产后确认到期 tick 不变。到期时房内身体、关联角色和远程查看均撤往对应联合国难民营，随后 surface 与列表记录消失。

## 星球特色词条

1. 星球页面每颗星球显示当前轮的 3 个不重复词条。
2. 重建任一星球后，确认该星球获得新一轮词条，保持打开的星球页面也会自动刷新。
3. 抽到 [planet=nauvis]“铁矿丰富”时，确认铁矿在该轮基础随机参数之上再次应用频率×4、矿区大小×4、丰度×16。
4. 确认互斥词条不会同轮出现，例如 [planet=gleba] 的潮湿季与干燥季、[planet=fulgora] 的大型岛屿与群岛。

## 屋主自购与税款

1. 房主列表中仍显示“购买”和“进入”，没有独立续期按钮。
2. 房主购买自己的房产，确认完整当前价成为新 P，D 重设为 `now+T`，余额净扣除交易税。
3. 重复自购不会受到旧 30 小时上限限制，每次都按当时完整报价重新成交。
4. 让第二名玩家买走房产，确认原主人获得 `floor(成交价×(1-基础税率/(卖方总等级/100+1)))`。
5. 确认税款差额被系统回收，没有凭空增加金币。
6. 修改管理员基础税率，确认普通交易和屋主自购都按卖方总等级降低实际税率。
7. 修改管理员房价倍率 a，确认只接受 `1<a<100`，且新成交后的即时报价随 a 改变。

## 房产关联箱

1. 房主进入房产，确认中央 2×2 格固定存在四个不可挖关联箱。
2. 通过公共关联箱放入非科技物品，确认房产关联箱看到同一末影库存。
3. 第二名玩家买走房产，确认房产内全部关联箱立即切到新主人的库存。
4. 原主人的公共关联箱仍然连接其自己的库存，不随房产转移。

## 管理员生命周期

1. 管理员应看到“管理”页，普通玩家不应看到；晋升和降级后打开窗口的页签立即变化。
2. 修改新账户金币、好友上限、新飞船价格/寿命、离线清理时间及房产税率，确认重新打开页面后仍保留。
3. 设置玩家金币后，确认余额立即变化并新增 `admin-balance:<管理员编号>` 流水。
4. 关闭公共星球重置后，星球页显示暂停且倒计时冻结；重新启用后从冻结值继续。
5. “管理员可进入任意房产”默认关闭，此时管理员遵守普通权限；启用后管理员可直接进入每套房产。

## 自然采样房产

1. 房产市场第一列、surface 本地化名称和房屋上方 rendering 必须一致：未命名时无主显示“无主房产”，有主显示“玩家名的房产”；悬停 tooltip 只显示尺寸。
2. 确认每套房产尺寸只能为 64×32、128×64 或 256×128，太阳能效率均为 10%，昼夜与所属星球同步。
3. 房产页有五颗星球页签；没有系统默认房产。每套房产中央为正方形教学网格，其余地砖和树石只能来自建造时选择的星球。
4. 房产内只复制自然样本中的树和岩石；不得出现虫巢、敌人、资源、建筑或其他来源实体。
5. 购买后让房主身体站在屋内执行 `/un-property rename 新名称`，确认列表、表面名和北侧名牌同步更新。
6. 非屋主、控制台、身体不在房产内或名称超过 64 字符时，重命名必须被拒绝。

## 玩家列表

1. 打开“玩家”页面，确认在线玩家排在前面，并显示在线/离线状态、总在线小时、离线小时和客户端语言。
2. 玩家加入、离开或切换客户端语言后，列表应自动刷新且顺序稳定。

## 经验与飞船

1. 通过关联库存出售不同科技瓶后，“经验”页按瓶种显示实际消耗瓶数。
2. 确认每项 1/10/100 瓶分别贡献 1/2/3 级，12 项贡献相加为总等级；界面不再额外显示“累计消耗 X 瓶”。
3. 在 [planet=nauvis] 花费配置金币建造飞船；重复建造必须被拒绝。
4. 确认新飞船宽度为 `16+总等级×2`，寿命为 `12+总等级` 小时；飞船页显示的剩余寿命会继续减少，且没有“进入飞船”按钮。
5. 确认建造与二次确认拆除位于飞船页顶部；个人页有五个自杀按钮，分别二次确认后在原地留下尸体，并将本次复活送到所选星球的联合国难民营。
6. 确认场景不提供五颗公共星球之间的直接传送；“家”按钮只在当前星球、该星球难民营和该星球房产之间往返。

## 星球状态与通知

1. 打开“星球”页，确认五颗公共星球按固定顺序仅显示图标、名称和 `时:分:秒` 重置倒计时，不显示通行状态或传送按钮。
2. 等待数秒，确认倒计时每秒下降，且仅刷新已打开该页的玩家 UI。
3. 在重置前 5 分钟确认全服收到预警；真正开始重置时再次收到关闭通知。
4. 完成一轮重置后，确认该星球的新倒计时落在 1～5 小时，并且保存重开不会重新抽取本轮周期。
4. 异步清理期间该星球显示“重建中”，完成后从新周期开始倒计时。

## 多人

1. 两名玩家同时对同一房产确认购买，最终只能按事件顺序完成，不能出现负余额或重复付款。
2. 两名玩家分别打开联合国窗口，一方成交后，另一方的列表应在一秒内刷新所有者和按钮。
3. 保存重开后，产权、基准价格、回落时间点、到期 tick 和关联箱主人保持不变。

## 科研限制

1. 研究“物流机器人”相关科技后，检查制作菜单，确认物流机器人配方仍处于禁用状态。
2. 保存重开或重新加载脚本后，该配方仍不能制作。

## 日志

检查 `factorio-current.log`，不应出现 `[un] event`、`property relink failed`、`failed to create property linked chests` 或金币处理错误。
