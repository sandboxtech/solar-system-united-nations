# 阶段 3 游戏内验证

## 初始化与联合国难民营

1. 新场景启动后确认每颗星球各有一套永久 64×32、128×64、256×128 基准房，分别按该星球从 1 开始编号；除此之外没有系统限时房产。
2. 新玩家背包获得铁板 500、铜板 200、石 100、木材 100；重新上线不会重复发放。
3. 管理员页不再提供动态房产供给、管理员创建或管理员删除入口。
4. 左上角只显示一个 United Nations of Sol 主菜单按钮和一个地图标记“家”按钮。
5. 从公共星球点击“家”，应前往该星球最近到访且仍自有的房产；没有自有房产时应前往该星球难民营。从房产或难民营点击则返回对应星球原点。
6. 从窗口的文字、表格、空白和内容区域拖动，确认整个非交互区域都可以移动窗口，按钮仍可正常点击。
7. 在任意星球难民营点击“家”，确认前往对应公共星球原点附近的空位；中心 32×32 应为教学网格，外围陆地应符合所属星球，最外两格应为该星球的代表液体地砖。
8. 进入载具后尝试传送，确认系统拒绝并提示先离开载具。
9. 没有个人关联箱时死亡并复活，确认最终位于联合国难民营原点附近。

## 关联箱传送与复活

1. 在 [planet=nauvis] 手动放置木箱，确认它被替换为个人关联箱。
2. 在其他星球或私人表面放置木箱，确认它仍然是普通木箱。
3. 确认主窗口有“玩法说明、个人、建造、房产、星球、飞船、玩家、阵营”页面；普通玩家看不到“管理”。个人页显示低保、体力和经验，飞船页顶部显示建造与拆除操作。
4. 离开该表面后点击“前往星球”，确认抵达关联箱附近的空位。
5. 角色死亡并复活，确认最终抵达关联箱附近的空位。
6. 挖掉关联箱不会改变“家”按钮的五星往返逻辑。
7. 再次死亡和点击“前往星球”，分别确认回到联合国难民营原点附近和 [planet=nauvis] 原点附近。
8. 用实体堵住目标附近所有安全落点，确认传送不会报错，而是强制抵达目标表面的 `(0, 2)`。

## 房价与购买

1. “房产”页面显示紧凑房产列表：房产、所有者、剩余寿命、当前价格和操作。
2. 第一次点击“购买”，按钮变为“确认 当前报价”，但不立即扣款。
3. 再次点击确认，确认扣除当前价格并取得产权。
4. 管理员把 a 设为 2；成交前价格为 `P`，成交后立即观察，下一次购买价应接近 `2P`。
5. 等待该房产自己的周期 T，确认价格回落到本次成交价 `P`，之后继续下降，最低为 1。
6. 如果确认前另一名玩家购买或屋主自购使价格上涨，旧报价应被拒绝并刷新。
7. 成交后确认所有在线玩家都收到买方、成交价、房产名、卖方（如有）、卖方实收及税款。

## 玩家建造与总寿命

1. 分别选择 30/120/480 小时，确认寿命成本档为 1/3/5；分别选择 64×32/128×64/256×128，确认尺寸成本档为 1/3/5。
2. 五颗星球依次显示自动化（红瓶）、冶金、农业、电磁和低温科技包经验；经验与金币费用均为 `1000×寿命成本×尺寸成本`。
3. 经验或体力不足时按钮禁用；补足后二次确认建造，确认永久扣除指定科技包经验和 10000 体力，不扣金币，其他经验不变。
4. 建成房产立即归建造者所有，只复制所选星球的自然地貌，并出现在对应星球房产页；确认初始 `P=10×经验成本`、`D=建造时刻`。
5. 成功后立即再次打开建造页，确认 20 小时冷却倒计时可见且不能建造；失败或取消不会进入冷却。
6. 交易房产后确认到期 tick 不变。到期时房内身体、关联角色和远程查看均撤往对应联合国难民营，随后 surface 与列表记录消失。

## 星球特色词条

1. 星球页面每颗星球显示当前轮的 3 个不重复词条。
2. 重建任一星球后，确认该星球获得新一轮词条，保持打开的星球页面也会自动刷新。
3. 抽到 [planet=nauvis]“铁矿丰富”时，确认铁矿在该轮基础随机参数之上再次应用频率×4、矿区大小×4、丰度×16。
4. 确认互斥词条不会同轮出现，例如 [planet=gleba] 的潮湿季与干燥季、[planet=fulgora] 的大型岛屿与群岛。

## 屋主自购与税款

1. 房主列表中仍显示“购买”和“进入”，没有独立续期按钮。
2. 房主购买自己的房产，确认完整当前价成为新 P，D 重设为 `now+T`，余额净扣除交易税。
3. 重复自购不会受到旧 30 小时上限限制，每次都按当时完整报价重新成交。
4. 让第二名玩家买走房产，确认原主人获得 `floor(成交价×(1-基础税率/(卖方总等级/100+1)))`。
5. 确认税款差额被系统回收，没有凭空增加金币。
6. 修改管理员基础税率，确认普通交易和屋主自购都按卖方总等级降低实际税率。
7. 修改管理员房价倍率 a，确认只接受 `1<a<100`，且新成交后的即时报价随 a 改变。

## 房产关联箱

1. 房主进入房产，确认中央 2×2 格固定存在四个不可挖关联箱。
2. 通过公共关联箱放入非科技物品，确认房产关联箱看到同一末影库存。
3. 第二名玩家买走房产，确认房产内全部关联箱立即切到新主人的库存。
4. 原主人的公共关联箱仍然连接其自己的库存，不随房产转移。

## 管理员生命周期

1. 管理员应看到“管理”页，普通玩家不应看到；晋升和降级后打开窗口的页签立即变化。
2. 修改新账户金币、好友上限、新飞船寿命、离线清理时间及房产税率，确认重新打开页面后仍保留。
3. 设置玩家金币后，确认余额立即变化并新增 `admin-balance:<管理员编号>` 流水。
4. 关闭公共星球重置后，星球页显示暂停且倒计时冻结；重新启用后从冻结值继续。
5. “管理员可进入任意房产”默认关闭，此时管理员遵守普通权限；启用后管理员可直接进入每套房产。

## 自然采样房产

1. 房产市场第一列、surface 本地化名称和房屋上方 rendering 必须一致：未命名时无主显示“无主房产”，有主显示“玩家名的房产”；悬停 tooltip 只显示尺寸。
2. 确认每套房产尺寸只能为 64×32、128×64 或 256×128，太阳能效率均为 10%，昼夜与所属星球同步。
3. 房产页有五颗星球页签；每颗星球只有四套永久基准房，其他房产均由玩家建造。每套房产中央为正方形教学网格，其余地砖和树石只能来自建造时选择的星球。
4. 房产内只复制自然样本中的树和岩石；不得出现虫巢、敌人、资源、建筑或其他来源实体。
5. 购买后让房主身体站在屋内执行 `/un-property rename 新名称`，确认列表、表面名和北侧名牌同步更新。
6. 非屋主、控制台、身体不在房产内或名称超过 64 字符时，重命名必须被拒绝。

## 玩家列表

1. 打开“玩家”页面，确认自己优先、在线玩家优先，离线玩家按最近上线时间排列，并显示在线/离线状态、总在线小时、离线小时和客户端语言。
2. 玩家加入、离开或切换客户端语言后，列表应在 5 秒内自动刷新且顺序稳定。

## 经验与飞船

1. 通过关联库存出售不同科技瓶后，“个人”页按瓶种显示实际消耗瓶数。
2. 确认每项 1/10/100 瓶分别贡献 1/2/3 级，12 项贡献相加为总等级；界面不再额外显示“累计消耗 X 瓶”。
3. 身体位于任意表面时，在飞船页建造飞船；轨道必须固定为当前阵营星球，成功时扣除 10000 体力而不扣金币，重复建造必须被拒绝。
4. 确认新飞船宽度为 `16+总等级×2`，寿命为 `12+总等级` 小时；飞船页显示的剩余寿命会继续减少，且没有“进入飞船”按钮。
5. 确认建造与二次确认拆除位于飞船页顶部；阵营页切换阵营时在原地留下尸体，并将本次复活送到目标阵营的联合国难民营。
6. 确认场景不提供五颗公共星球之间的直接传送；“家”按钮只在当前星球、该星球难民营和该星球房产之间往返。

## 起始套装

1. 新玩家在“个人”页点击套装按钮，第一次只进入确认状态，第二次扣除 10000 体力，不扣金币。
2. 装甲栏为空时，确认模块装甲自动穿戴，个人机器人指令模块和 6 块太阳能板进入装备栏，5 台建设机器人进入背包。
3. 已穿装甲时再次购买，确认不会覆盖现有装甲；新套装物品进入背包，放不下的物品掉在角色脚下。
4. 体力不足时按钮禁用；重复购买每次都正常扣除 10000 体力。

## 星球状态与通知

1. 打开“星球”页，确认五颗公共星球按固定顺序仅显示图标、名称和 `时:分:秒` 重置倒计时，不显示通行状态或传送按钮。
2. 等待数秒，确认倒计时每秒下降，且仅刷新已打开该页的玩家 UI。
3. 在重置前 5 分钟确认全服收到预警；真正开始重置时再次收到关闭通知。
4. 完成一轮重置后，确认该星球的新倒计时落在管理员设置的上下限内（默认 0.5～2.5 小时），并且保存重开不会重新抽取本轮周期。分别用 a=2、1、0.5 多轮抽样，确认分布依次偏短、均匀、偏长。
5. 异步清理期间该星球显示“清理地图”，完成后从新周期开始倒计时。

## 多人

1. 两名玩家同时对同一房产确认购买，最终只能按事件顺序完成，不能出现负余额或重复付款。
2. 两名玩家分别打开联合国窗口，一方成交后，另一方的列表应在一秒内刷新所有者和按钮。
3. 保存重开后，产权、基准价格、回落时间点、到期 tick 和关联箱主人保持不变。

## 犯罪

1. 普通玩家在“房产”页看到犯罪按钮，但没有独立“犯罪”页；不能看到“管理”页，也看不到玩法说明中的“管理说明”子标签。尝试通过界面事件打开管理页应回到玩法说明。
2. 身体位于太空平台时犯罪按钮禁用；remote view 停留在太空、但身体在星球关联表面时，仍按身体位置判定。
3. 当前所属星球全部房产无主时按钮禁用；其他星球的有主房产不应成为目标。
4. 金币少于 1000 或体力少于 10000 时按钮禁用。条件满足后点击，确认固定扣除两项费用。
5. 目标成功率应为 `1/(1+当前报价/10000)`；成功时绕过普通访客权限进入目标房产，失败时留在原处。
6. 两名玩家分别观察全服通知，确认成功和失败均显示犯罪者、目标房产和本次成功率。

## 科研限制

1. 研究“物流机器人”相关科技后，检查制作菜单，确认物流机器人配方仍处于禁用状态。
2. 保存重开或重新加载脚本后，该配方仍不能制作。
3. 星球页显示每小时科技漏水倒计时；运行 `/sc require('scripts.technology_decay').run()` 可立即触发一轮管理员测试。
4. 确认触发式科技不会失传，当前研究的直接前置科技不会失传；更早的间接前置仍参与判定。
5. 确认普通科技命中后撤销，无限科技命中后只降低一级；通知使用科技图标并显示降级后的等级。
6. 在管理员页关闭科技漏水，确认星球页显示“已关闭”且不再触发；重新开启后从当前时刻开始完整的新周期。
7. 修改科技漏水周期，确认倒计时从当前时刻重新排期；修改最大强度后，下一轮使用新值。

## 建房动态设置

1. 把某颗星球的房产软上限调到当前房产数，确认该星球建造按钮禁用，其他星球不受影响。
2. 调高上限后确认恢复建造；把上限调低至现有数量以下，确认已有房产不会被删除。
3. 修改三档总寿命与三档 T，重新打开建造页确认寿命下拉文本同步变化，新房的到期时间和价格周期采用新值。
4. 修改新房初始价格倍率，确认之后新建房产的 P 使用新倍率，已有房产价格不变。
5. 打开地图和远程查看的表面列表，确认永久无主房与玩家房产均对玩家势力隐藏，但仍可通过房产页的“进入”按钮正常抵达。

## 阵营与说明界面

1. “阵营”标签使用 `[space-location=solar-system-edge]`；表格只显示阵营、关系、在线/总人数、房产、飞船和切换，不显示累计在线小时。
2. 鼠标停在其他阵营的加入按钮上，确认显示 10000 体力、旧阵营房产与飞船损失，以及固定 60 秒复活且不额外扣复活体力。
3. 完成阵营切换并复活后，确认全服收到“玩家加入阵营”的通知；玩家 force、房产列表和新飞船轨道均对应新阵营。
4. 普通玩家的玩法说明依次显示故事、简要、进阶、完整四档；管理员额外看到管理说明。简要只讲开局循环，进阶只讲系统衔接，完整只讲公式与边界。
5. 检查个人、房产、玩家和飞船页的信息图标或按钮 tooltip，确认分别承载低保/体力/经验、房产权限/犯罪、好友/转账和飞船精确规则。

## 日志

检查 `factorio-current.log`，不应出现 `[un] event`、`property relink failed`、`failed to create property linked chests` 或金币处理错误。
