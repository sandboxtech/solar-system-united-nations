# 阶段 3 游戏内验证

## 初始化与联合国避难所

1. 重新加载场景脚本；如未出现默认房产，执行 `/un-property repair`。
2. 新场景执行 `/un-property list`，确认存在 9 套默认房产；每套长宽都只能是 32、64 或 128，并可出现方形、横向长方形和纵向长方形。
3. 左上角应显示垂直对齐的白色标题及低保、[planet=nauvis]、避难所、自杀、飞船、最近房产、房产、经验、玩家图标，不显示额外角色徽记；两个目的地按钮应直接传送，飞船按钮打开只含飞船内容的“飞船”页。
4. 进入一套自己的房产后点击“最近房产”顶层图标，应直接返回该房产；房产易主后再次点击必须被拒绝。
5. 从窗口的文字、表格、空白和内容区域拖动，确认整个非交互区域都可以移动窗口，按钮仍可正常点击。
6. 点击“前往避难所”，确认安全传送到 64×64 的“联合国避难所”原点附近；地面应为教学网格地格。
7. 在没有个人关联箱时点击 [planet=nauvis] 图标，确认前往 [planet=nauvis] 原点附近的空位。
8. 进入载具后尝试传送，确认系统拒绝并提示先离开载具。
9. 没有个人关联箱时死亡并复活，确认最终位于联合国避难所原点附近。

## 关联箱传送与复活

1. 在 [planet=nauvis] 手动放置木箱，确认它被替换为个人关联箱。
2. 在其他星球或私人表面放置木箱，确认它仍然是普通木箱。
3. 确认主窗口不再有“传送”页；“飞船”页只显示飞船状态、建造和拆除。
4. 离开该表面后点击“前往星球”，确认抵达关联箱附近的空位。
5. 角色死亡并复活，确认最终抵达关联箱附近的空位。
6. 挖掉关联箱后再次前往 [planet=nauvis]，应改为抵达原点附近。
7. 再次死亡和点击“前往星球”，分别确认回到联合国避难所原点附近和 [planet=nauvis] 原点附近。
8. 用实体堵住目标附近所有安全落点，确认传送不会报错，而是强制抵达目标表面的 `(0, 2)`。

## 房价与购买

1. “房产”页面显示紧凑房产列表：房产、所有者、当前价格和操作。
2. 第一次点击“购买”，按钮变为“确认 当前报价”，但不立即扣款。
3. 再次点击确认，确认扣除当前价格并取得产权。
4. 成交前价格为 `P`；成交后立即观察，下一次购买价应接近 `10P`。
5. 使用加速测试或等待两小时，确认价格回落到本次成交价 `P`，之后继续下降，最低为 1。
6. 如果确认前另一名玩家购买或房主续期使价格上涨，旧报价应被拒绝并刷新。

为了快速测试，可以创建低价房产：

```text
/un-property create 10 32 128
```

该房产应为 32×128；省略长宽时，两边分别从 32、64、128 中随机选择。

## 续期与税款

1. 房主列表中显示“进入”和“续期 费用”。
2. 点击续期，确认扣除 `ceil(P×tax)` 并将价格基准时间向未来延长两小时。
3. 重复续期，确认超过 `now+30小时` 后被拒绝。
4. 让第二名玩家买走房产，确认原主人获得 `floor(成交价×(1-tax))`。
5. 确认税款差额被系统回收，没有凭空增加信用。
6. 确认税率和续期费均按 10% 计算。

## 房产关联箱

1. 房主进入房产，确认中央 2×2 格固定存在四个不可挖关联箱。
2. 通过公共关联箱放入非科技物品，确认房产关联箱看到同一末影库存。
3. 第二名玩家买走房产，确认房产内全部关联箱立即切到新主人的库存。
4. 原主人的公共关联箱仍然连接其自己的库存，不随房产转移。

## 管理员生命周期

1. `/un-property create [价格] [长] [宽]` 可以按指定尺寸创建房产；长宽只能为 32、64、128，省略时随机。创建后地图应已完整探索。
2. 执行 `/un-property delete <编号>`，确认只显示删除预览。
3. 一分钟内执行 `/un-property delete-confirm <编号>`，确认空房产进入删除队列。
4. 玩家身体位于或正在远程查看房产时，删除必须被拒绝。
5. 删除完成后，房产从 UI 和 `/un-property list` 中消失。
6. 管理员在每套房产行都能直接进入，即使不是房主或身体不在 [planet=nauvis]。

## 自然采样房产

1. 新场景的九套默认房产应使用“房产 + 编号”，悬停名称可查看尺寸、形状、采样星球和太阳能倍率。
2. 确认每套房产的长宽均来自 32、64、128，且默认清单覆盖 10%/100%/1000% 太阳能档位。
3. 每套房产只有中央 6×6 区域使用教学网格；其余地砖应连续对应 [planet=nauvis] 或 [planet=gleba] 的远方自然地貌。
4. 房产内只复制自然样本中的树和岩石；不得出现虫巢、敌人、资源、建筑或其他来源实体。
5. 购买后让房主身体站在屋内执行 `/un-property rename 新名称`，确认列表、表面名和北侧名牌同步更新。
6. 非屋主、控制台、身体不在房产内或名称超过 64 字符时，重命名必须被拒绝。
7. 旧房产不自动迁移地形或名称；必须以新场景或新建房产验证采样效果。

## 玩家列表

1. 打开“玩家”页面，确认在线玩家排在前面，并显示在线/离线状态、总在线小时、离线小时和客户端语言。
2. 玩家加入、离开或切换客户端语言后，列表应自动刷新且顺序稳定。

## 经验与飞船

1. 通过关联库存出售不同科技瓶后，“经验”页按瓶种显示实际消耗瓶数。
2. 确认每项 1/10/100 瓶分别贡献 1/2/3 级，12 项贡献相加为总等级；界面不再额外显示“累计消耗 X 瓶”。
3. 在 [planet=nauvis] 花费配置信用建造飞船；重复建造必须被拒绝。
4. 确认飞船显示约 50 小时寿命，界面没有“进入飞船”按钮；拆除和自杀均需要点击两次确认。
5. 在任一公共星球、联合国避难所和本人房产之间来回传送，确认三类区域互通；从飞船等其他私人表面发起时应被拒绝。

## 多人

1. 两名玩家同时对同一房产确认购买，最终只能按事件顺序完成，不能出现负余额或重复付款。
2. 两名玩家分别打开联合国窗口，一方成交后，另一方的列表应在一秒内刷新所有者和按钮。
3. 保存重开后，产权、基准价格、续期时间和关联箱主人保持不变。

## 科研限制

1. 研究“物流机器人”相关科技后，检查制作菜单，确认物流机器人配方仍处于禁用状态。
2. 保存重开或重新加载脚本后，该配方仍不能制作。

## 日志

检查 `factorio-current.log`，不应出现 `[un] event`、`property relink failed`、`failed to create property linked chests` 或信用处理错误。
